Agentic Plugin Marketplace

Open source plugins for seven AI coding tools

The Agentic Plugin Marketplace is Seth Hobson's open-source set of plugins for AI coding tools. It contains 94 plugins, 202 agents, 184 skills, 105 commands, and 16 orchestrators, which are commands that coordinate several agents on one task. The repository keeps one Markdown source and converts it to the formats that Claude Code and six other AI coding tools expect.

How it works

The repository keeps the instructions in Markdown files and converts them into the format that each supported tool expects. A plugin can combine specialist agents, skills, commands, and orchestrators, and installing one plugin doesn't load the rest of the marketplace into the session.

Because each plugin loads only its own files, the model's context holds only what the current task needs. Maintainers edit one shared source, and the build converts that source for every supported tool.

Install the marketplace

In Claude Code, you add the repository as a marketplace and then install only the plugins you need:

/plugin marketplace add wshobson/agents

The GitHub repository has the full plugin catalog, the setup steps for each supported tool, and the source for every plugin.
