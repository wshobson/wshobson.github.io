Agentic Plugin Marketplace

Open source plugins for seven AI coding tools

The Agentic Plugin Marketplace is Seth Hobson's open-source set of plugins for AI coding tools. It contains 94 plugins, of which 92 are local and 2 are external, and the local plugins hold 202 agents, 185 skills, and 105 commands. Each component is written once in Markdown, and adapters convert it to the formats that Claude Code and six other AI coding tools expect.

How it works

Contributors write each agent, skill, and command once, in Markdown, in the Claude Code plugin format. A plugin groups related components, and installing one plugin doesn't load the rest of the marketplace into the session. Because each plugin loads only its own files, the model's context holds only what the current task needs.

Adapters generate the format that each other tool reads. They map model names to that tool's models and translate tool permissions where the tool supports them. CI regenerates the files for every tool, validates them, and runs the OpenCode, Antigravity CLI, and Pi files through those tools' installed CLIs.

Install the marketplace

In Claude Code, you add the repository as a marketplace and then install only the plugins you need:

/plugin marketplace add wshobson/agents
/plugin install python-development@claude-code-workflows

The GitHub repository has the full plugin catalog, the setup steps for each supported tool, and the source for every plugin.
