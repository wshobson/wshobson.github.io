Tiingo MCP Server

Open source Tiingo market data for MCP clients, written in Rust

Tiingo MCP is a Rust server for the Model Context Protocol (MCP) from Major 7 Apps, the company I founded. It gives Claude Code, Claude Desktop, and other MCP clients 38 tools for Tiingo market data: stock prices, forex rates, crypto prices, fund data, financial news, company fundamentals, and corporate actions such as dividends and splits. Prebuilt binaries for macOS, Linux, and Windows mean you can install it without Rust.

At a glance

  • Publisher: Major 7 Apps, the company I founded
  • Contents: 38 tools, 3 fixed resources, 1 resource template, and 5 prompts
  • Data source: the Tiingo API, which needs an API key. The data you can reach depends on the features enabled for your key.
  • Installation: Homebrew, an install script, a Windows installer, a Claude Desktop bundle, or Cargo
  • Transport: stdio, where the MCP client starts the server as a child process
  • Language: Rust
  • License: MIT

Data coverage

FundsMutual fund and ETF fee metadata and fee metrics
ResearchAsset search, financial news, company fundamentals, and financial statements
Corporate actionsDividends, distributions, dividend yield, and splits
Live dataShort, bounded subscriptions to Tiingo's live IEX and consolidated equity feeds

Some of these Tiingo datasets are in beta or need specific account features. A REST call uses API quota and bandwidth, and a live subscription uses bandwidth.

Install the server

On macOS, install with Homebrew, then add the server to Claude Code with your Tiingo API key:

brew tap major7apps/tiingo-mcp https://github.com/major7apps/tiingo-mcp
brew install major7apps/tiingo-mcp/tiingo-mcp
claude mcp add tiingo --env TIINGO_API_KEY=your-api-key-here -- tiingo-mcp

The GitHub repository covers the other installation methods, the configuration for other MCP clients, every tool, and the access rules for each dataset.
