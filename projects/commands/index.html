cat execution-model.md

Workflows and tools

A workflow command coordinates several specialist agents on a larger task, e.g., feature delivery, incident response, or security hardening. A tool command does one narrow task, e.g., scaffolding an API, auditing accessibility, generating tests, or reviewing a data pipeline.

The split let a user run a whole multistep task with one workflow, or run one narrow task with a single tool and no extra agents.
