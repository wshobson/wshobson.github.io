Pensyve Agent Memory Runtime

Open source agent memory that runs locally

Pensyve is Major 7 Apps' open-source runtime for persistent AI agent memory. It stores facts, conversations, observations, and action outcomes so an agent can retrieve them in later sessions. Its Rust engine keeps memory in local SQLite and runs embedding models locally, and you can use it from Python, an MCP server, a command-line tool, or a REST API. Local use doesn't need a Pensyve account or API key.

How agent memory works

Pensyve stores memory outside the language model. Your application saves facts or conversations, searches for relevant records, and adds the results to a later prompt. Reusing the same storage path and namespace lets an agent retrieve information across processes and sessions. Saving a memory doesn't train the model or change its weights.

Local use keeps memory on your own machine without a hosted service. Embedding models may download the first time they load, so prepare the model files before running without network access. To share one memory store, run the HTTP gateway with SQLite or PostgreSQL.

ls memory/

Memory model

RecordRole
Facts (semantic)Stores facts about users, projects, or other named entities
Conversations (episodic)Records the messages and outcome of a session as an episode
Action outcomes (procedural)Records the results of actions an agent took
ObservationsRecords what an agent noticed, for recall in later sessions
Retrieval and forgettingCombines up to eight ranking signals, promotes repeated facts, and updates retention with an FSRS forgetting curve

Your integration decides what to record and when to retrieve it. Recording a conversation doesn't automatically turn it into a successful procedure.

Use from an existing stack

Install the SDK for your language. The Python SDK runs the engine inside your process, and the TypeScript and Go SDKs connect to an HTTP gateway that you run:

pip install pensyve
npm install @pensyve/sdk
go get github.com/major7apps/pensyve/pensyve-go/v5@latest

The source repository covers the MCP server for Claude Code, Codex, and Cursor, the HTTP gateway, the command-line tool, and the LangChain and LangGraph adapters.
